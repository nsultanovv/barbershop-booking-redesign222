## Documentation

This folder is intended for extended documentation for the Barber Shop Booking System.

- **Architecture**: High-level system overview, diagrams, and component responsibilities.
- **API**: Detailed REST API reference for the Spring Boot backend.
- **Frontend**: Notes on the Next.js app structure, routing, and styling patterns.
- **Deployment**: Environment variables, Render and Vercel configuration details.

For a quick start and main project description, see the root `README.md`.
